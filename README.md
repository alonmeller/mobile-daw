# Mobile DAW

אפליקציית הקלטה ויצירת מוזיקה לאנדרואיד: זרימת עבודה בסגנון REAPER, עיצוב בהשראת GarageBand.

## התקנה בטלפון

1. פתח בטלפון את עמוד ה-[Releases](../../releases) של המאגר.
2. בגרסה העליונה, לחץ על `MobileDAW.apk` כדי להוריד.
3. פתח את הקובץ שהורד. אם אנדרואיד שואל, אשר "התקנה ממקורות לא ידועים" עבור הדפדפן.

כל גרסה חדשה מותקנת מעל הקודמת, והפרויקט השמור נשאר.

## מה יש כרגע (שלב 1)

- הקלטה מהמיקרופון, כולל הקלטה תוך כדי ניגון של ערוצים קיימים
- כפתור "+ Track" להוספת ערוץ ריק, וכפתור R לבחירת הערוץ שאליו מקליטים
- ניגון רב-ערוצי בהשהיה נמוכה (מנוע C++ מבוסס Oboe)
- מטרונום וטמפו
- תצוגת גלי קול, סרגל תיבות, זום וגלילה
- עוצמה, Mute ו-Solo לכל ערוץ, ומדי עוצמה
- הזזת קטעים בגרירה ומחיקת ערוצים
- שמירה אוטומטית של הפרויקט

## עריכה (שלב 2, לפי פרקים 2, 7 ו-9 במדריך של REAPER)

- כמה קטעים (Items) בכל ערוץ. הקלטה חדשה מחליפה את מה שמתחתיה, כמו Punch-in
- הקשה על קטע בוחרת אותו. גרירה של קטע מזיזה אותו, וגרירה של שטח ריק גוללת
- בקטע נבחר: גרירת הקצוות מקצצת, וגרירת העיגולים הלבנים למעלה יוצרת Fade In ו-Fade Out
- Split בנקודת הניגון, Duplicate, Copy/Paste, Delete, Mute לקטע, Normalize, והעברה לערוץ למעלה או למטה
- Undo ו-Redo לכל פעולה
- הצמדה לגריד (Snap) עם גריד של תיבה, 1/2, 1/4, 1/8 או 1/16
- לופ: גרירה על הסרגל מסמנת את טווח הלופ, וכפתור ⟳ מפעיל ומכבה אותו
- סמנים: כפתור "+ Marker", קפיצה בין סמנים, הקשה על סמן קופצת אליו, ולחיצה ארוכה מוחקת אותו

## מבנה הקוד

- `app/src/main/cpp` מנוע האודיו (C++ / Oboe)
- `app/src/main/java/.../ui` הממשק (Jetpack Compose)
- `app/src/main/java/.../model` מודל הפרויקט, פעולות העריכה וההיסטוריה (עם בדיקות ב-`app/src/test`)
- `app/src/main/java/.../data` שמירת פרויקט וקבצי WAV
